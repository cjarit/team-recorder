**Code facts found during the read**

- Dead button: "Open Project Folder" (SBC L625; handler L632-633) does nothing, because `projectDirectory` is always nil (WM L40).
- Start Recording is enabled in the Error state while the watcher runs (SBC L551). The popover offers Start only in Ready (PV L112). Menu and popover disagree.
- Stop Watcher is in the menu (row 6) and in no popover state and no spec window (spec gap).
- Default meeting text differs: "Meeting" in the menu (SBC L509, L691) vs "Teams Meeting" in the popover (PV L85).
- The PoC popover shows all three permission rows always (PV L53-55). FR-POP-006 says only when missing.
- The PoC error card title is orange text (PV L229-231). FR-POP-005 wants primary text with an orange icon.
- ⌘Q at PV L62 is a text label only. PopoverView.swift attaches no keyboard shortcut.
